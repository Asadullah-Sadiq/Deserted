# Digitech Offerings

World-class B2B AI & Tech Services website built with React 18 + Vite.

## Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS v3
- **Animation**: Framer Motion, GSAP
- **3D**: Three.js / React Three Fiber (with CSS fallback)
- **Routing**: React Router v6
- **Forms**: React Hook Form + Zod validation
- **Notifications**: React Hot Toast
- **Smooth Scroll**: Lenis
- **Icons**: Lucide React
- **State**: Zustand
- **Backend**: Firebase v10 (Firestore + Auth)
- **Email**: EmailJS

## Pages

- `/` — Home (Hero, TechStack ticker, Services, Stats, Testimonials, CTA)
- `/services` — Detailed services breakdown (AI/ML, Cloud, Data, Security, Product, Digital)
- `/about` — Company story, values, team, process
- `/contact` — Contact form with EmailJS integration

## Running the App

```bash
npm run dev
```

Runs on port 5000.

## Environment Variables

Copy `.env.example` to `.env` and fill in your credentials:
- Firebase config (from Firebase Console)
- EmailJS config (from emailjs.com)

## User Preferences

- Dark mode by default
- Syne font for headings, DM Sans for body
- Indigo/violet/cyan color palette
- Glass morphism card style
