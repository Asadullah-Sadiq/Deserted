GLOBAL ANIMATIONS:

1. PAGE LOAD SEQUENCE:
   - Loader: full screen, logo animates in, progress bar, fades out (1.5s)
   - Then hero section staggered reveal

2. SCROLL ANIMATIONS (Framer Motion whileInView):
   - All sections: fade up (y: 40 → 0, opacity: 0 → 1)
   - Stagger children with 0.1s delay each
   - Once: true (don't re-trigger)

3. CURSOR (Desktop only):
   - Custom cursor: small dot (8px) that follows instantly
   - Larger ring (40px) that follows with spring lag
   - On hover of links/buttons: ring expands (60px) + changes color

4. SMOOTH SCROLLING:
   - Lenis for buttery smooth scroll
   - Integrated with Framer Motion scroll progress

5. PARALLAX:
   - Hero background moves at 0.5x scroll speed
   - Floating badges move at 0.8x
   - Use useScroll + useTransform from Framer Motion

6. MICRO-INTERACTIONS:
   - Button: shimmer sweep on hover (pseudo-element animation)
   - Card: border glow pulses on hover
   - Nav links: underline draws from left
   - Form inputs: label floats up on focus (floating label pattern)
   - Stars: each star animates in with pop effect

7. 3D TILT EFFECT on service cards:
   - Mouse move over card → card tilts in 3D (perspective: 1000px)
   - Use react-tilt or manual transform calculation
   - Subtle inner glow follows mouse position
